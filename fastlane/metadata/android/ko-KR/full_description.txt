LetterBox는 글자를 배우기 시작한 어린아이를 위한 게임입니다. 그림 하나(대개 동물)와 글자 세 개가 나옵니다. 낱말이 시작하는 글자를 누르세요. 그림을 누르면 이름을 읽어 줍니다.

틀리면 같은 그림이 다시 나와서 아이가 한 번 더 도전할 수 있습니다. 점수도, 시간 제한도, 벌칙도 없습니다.

<b>기능</b>
<ul>
<li>아홉 가지 언어: 영어, 독일어, 프랑스어, 스페인어, 이탈리아어, 폴란드어, 브라질 포르투갈어, 일본어(히라가나), 한국어(한글). 언어는 시스템 언어와 상관없이 메뉴에서 고를 수 있습니다.</li>
<li>약 70장의 그림. 많은 글자에 그림이 여러 장 있어서 매번 새롭습니다.</li>
<li>연습할 글자를 고를 수 있습니다: 전체, 가장 자주 쓰이는 열 글자, 또는 한 글자만.</li>
<li>선택형 학습 기록: 아이가 잘 아는 글자는 덜 나옵니다. 몇 주 동안 연습하지 않으면 기록이 천천히 줄어들어 잊은 글자가 다시 나옵니다.</li>
<li>실물 키보드로도 할 수 있습니다: 1, 2, 3 키나 해당 글자 키를 누르세요.</li>
<li>앱을 닫을 때까지 메뉴 버튼을 숨길 수 있어서 작은 손이 실수로 설정을 바꾸지 않습니다. 화면 오른쪽 위를 길게 누르면 다시 나타납니다.</li>
</ul>

<b>개인정보</b>
LetterBox는 어떤 권한도 요청하지 않으며 인터넷에 연결하지 않습니다. 광고도 추적도 없습니다. 학습 기록은 기기에만 저장되며 클라우드 백업에서 제외됩니다.
